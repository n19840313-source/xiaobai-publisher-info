工具說明

更新日期：2026-10-15。

這是管理者本人頻道使用的 Windows 本機工具，使用 Google OAuth 2.0 與 YouTube Data API 服務，管理影片文案及繁體中文、越南文、英文字幕。提供上傳可見性選擇、既有字幕新增或更新、全文下載核對、隱私政策入口與清除清單。

此頁是公開說明文件，並非線上登入服務。新三語管理功能已完成本機與隔離測試；尚未以新版本對正式影片做三語寫入驗證。每日10支影片、每支3語為未來容量規劃，並非目前實際API用量。

本機使用流程

開啟桌面工具，先閱讀隱私政策，再由使用者確認素材、文案與授權。Google 登入在 Google 官方網頁完成；本工具不取得 Google 密碼。既有影片管理先預覽，再確認影片ID及內容，核對指定頻道後才執行。資料清除先列清單，確認後才操作。
