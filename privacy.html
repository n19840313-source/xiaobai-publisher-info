隱私權政策

更新日期：2026-10-15。適用工具：小白古風內容發布工具。

用途與適用範圍

本工具為頻道管理者使用的 Windows 本機程式，使用 YouTube API 服務及 Google OAuth 2.0，協助核對授權頻道、上傳已確認的影片、編輯標題與說明、設定縮圖、新增或更新繁體中文、越南文及英文字幕，下載字幕全文核對文字與時間碼，並回查發布與字幕狀態。本版本供管理者本人頻道使用。

字幕由使用者提供，不自動翻譯。既有影片管理維持原可見性；新影片上傳可選公開、不公開或私人，執行前顯示所選設定。Google 審核與專案限制仍可能阻擋某些可見性。

讀取及處理的資料

工具處理使用者自行選擇的影片、照片、縮圖、字幕、標題及說明，以及必要的本機檔案路徑；透過官方 API 讀取授權頻道識別、影片與字幕識別碼、內容設定、處理結果與 API 錯誤狀態。這些資料只用於使用者指定的發布、帳號核對、結果查驗及避免重複發布。

儲存、安全及分享

Google 授權權杖以 Windows 使用者加密機制存放於本機；API 發布狀態及專用暫存也留在本機。工具不要求或保存 Google 帳戶密碼，不向其他社群平台提供 YouTube 權杖。使用者確認發布或管理工作後，所選內容及必要資料才會傳送給 Google／YouTube，並依其政策處理。

發布程式不會將這些資料送往人工智慧服務，沒有資料販售、廣告追蹤或第三方廣告功能。其他平台功能使用各自的授權；本次隱私管理不會啟用取消的平台。

Google 對資料的處理請參閱 Google 隱私權政策。授權會使用外部瀏覽器與 Google 官方登入頁；這些網站可能依其政策使用 Cookie。本機隱私管理頁不使用廣告 Cookie，僅在記憶體保存表單驗證資訊，不提供對外網路服務。

保留期限與使用者選擇

授權權杖僅在授權有效且有必要時保留。API 資料以完成指定工作所需的最短期間保留，最長 30 天；管理者須在期限內透過資料管理功能清除，或重新向官方 API 更新仍需使用的資料，不能無限期保留舊 API 回應。本機原始影片、照片、使用者自行撰寫的文案與字幕，不因 API 暫存清除而刪除。

「隱私政策／資料管理與清除」入口常駐於工具主視窗。首次存取 YouTube 功能前，須閱讀並同意本政策；政策內容改變後須重新同意。同意紀錄僅保存政策版本、內容雜湊與同意時間，不記錄地址或 Google 密碼。

撤銷授權與資料清除

使用者可在工具中選擇「預覽清除清單」，查看完整路徑、數量與容量，再輸入確認文字執行「撤銷 YouTube 授權並清除此清單」。程式會向 Google 官方撤銷端點提出要求，確認成功後移除 YouTube 加密權杖、專用 API 暫存並清空清單中的發布狀態。發布狀態只留下不包含影片或字幕識別碼的已清除標記，阻擋誤重傳。

預覽不撤銷、不刪除。清單或檔案有變更時停止執行；已有 YouTube 工作執行時拒絕清除。撤銷或清除結果不明時，不宣稱成功，工具維持停止存取並要求完成待辦。操作不會刪除 YouTube 平台上的內容；如需刪除平台內容，請在 YouTube 或 YouTube Studio 另行操作。其他平台的本機授權檔保留。

Google 官方撤銷可能取消同一專案下的其他 OAuth 權限。偵測到本機相簿授權且無法證明專案隔離時，本工具會阻擋自動撤銷，避免連帶影響相簿。使用者可另外選擇「只清除本機資料並停止工具存取」：此方式移除本機 YouTube 權杖、清除相關 API 資料並停止工具存取，不向 Google 撤銷權限，也不代表 Google 帳戶授權已取消。由 Google 安全設定完成撤銷後，亦可用此方式完成本機清除。兩種操作分開顯示，不會互相冒稱。

使用者也可由 Google 帳戶第三方存取權設定 撤銷授權。由工具提出的刪除要求應儘速完成，最遲於 7 個日曆天內完成；由 Google 安全設定撤銷時，管理者須同步清除相關 API 資料，並至少每 30 天確認授權與資料保留狀態。這些期限是資料管理義務，不代表本工具已設置常駐背景監控或會在電腦關閉時執行。

程式管理的清單涵蓋 YouTube 加密授權、短片工作的 youtube.json 及結果.json 中的 YouTube 欄位、現行單曲的 YouTube發布狀態.json、相關固定名稱的寫入暫存檔，以及專用 youtube_api_cache 目錄內的 API 暫存。結果檔的其他平台欄位保留。使用者另行匯出的文件、截圖或其他位置的備份，須另外檢視並清除其中不再需要的 API 資料；工具不會任意掃描整台電腦或刪除原始媒體。
