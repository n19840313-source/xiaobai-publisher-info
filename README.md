# 小白古風內容發布工具

更新日期：2026-09-11

## 工具說明

本工具是「小白的古風世界」管理者自用的 Windows 桌面程式，用於整理本機影片、圖片、標題、介紹及字幕，經帳號核對後透過平台官方介面上傳。工具目前正在測試，不對外提供付費服務。

TikTok 功能採草稿上傳流程：使用者授權後選擇影片，工具將影片送至 TikTok 收件匣，使用者須在 TikTok 檢查介紹、內容標示及可見性並完成發布。目前尚未完成 TikTok 帳號連接與實際上傳驗證，不宣稱已取得直接公開發布資格。

官方頻道：https://www.youtube.com/@xiaobai.gufeng

TikTok 帳號：https://www.tiktok.com/@xiaobai.gufeng

## 隱私權政策

本工具僅處理使用者主動選取的發布素材、文字、帳號識別及平台回傳的處理結果。資料用途為核對帳號、執行指定上傳、查詢狀態及避免重複發布。

平台授權憑證以 Windows 加密機制存放於使用者本機；工作資料及上傳日誌亦保存在本機。工具不要求或保存平台登入密碼。使用者授權執行上傳後，所選影片及必要資料會傳送至對應平台；各平台依各自政策處理資料。

本工具沒有廣告、資料販售或將授權資料提供其他平台的功能。發布程式本身不呼叫人工智慧服務處理使用者資料。本公開文件庫只提供說明文件，不收集影片或授權憑證；網站託管服務可能依其隱私政策記錄瀏覽資訊。

使用者可在 TikTok 的帳號安全與應用程式權限設定撤銷本工具授權。停止使用後，可刪除本機憑證、工作檔及日誌；目前尚無整合式自動清除與期限管理功能。刪除本機資料不會刪除已傳至平台的內容，平台內容須另行刪除。

政策若調整，會在此頁更新日期及內容。疑問可透過本文件庫的議題頁聯繫管理者，請勿附上密碼、權杖或其他敏感資料。

本工具供頻道管理者自用測試，使用者只應上傳有權使用的素材，並遵守所用平台的服務條款、著作權與內容規範。

執行前應確認帳號、影片及文字。草稿送達不代表影片已公開；發布仍須在 TikTok 完成操作。平台審核、配額與權限可能影響結果，本工具不保證上傳成功或公開可見。
